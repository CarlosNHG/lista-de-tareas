# 📝 Lista de Tareas en HTML, CSS y JavaScript

Este proyecto es una práctica de FrontEnd donde se crea una aplicación de lista de tareas como primera interaccion con JS.

## 🧱 Funcionalidades por versiones

- **v1:** HTML + CSS básico
- **v2:** Agregar tareas dinámicamente
- **v3:** Guardado con localStorage
- **v4:** Marcar tareas completadas
          Filtros (todas, pendientes, completadas)
          Contador de tareas pendientes
          Edición con doble clic

## 🚀 Cómo usar
1. Clona el repo
2. Abre `index.html` con Live Server o navegador
